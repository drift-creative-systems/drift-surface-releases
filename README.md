# Drift: Surface — releases

Release builds of the **Drift: Surface** WordPress plugin by [Drift Creative Systems](https://driftcreativesystems.co.uk/), for Drift: Surface band and artist websites (it pairs with the Drift: Surface Theme). This repo holds nothing but releases: the plugin's source is in a private repo.

Installed sites check here for updates automatically and offer them in **Dashboard → Updates**. Each release has one asset, `drift-surface.zip`, which is the only file sites install.

To install by hand, download `drift-surface.zip` from the [latest release](../../releases/latest) and upload it in **Plugins → Add New → Upload Plugin**.

Releases are published by the source repo's `tools/release.py`. Don't commit anything else here, and don't attach other files to a release.

Support: https://support.driftcreativesystems.co.uk/

`LICENSE` is the licence each release ships under (the same file is in the zip).
